## 📚 What You Will Learn

### 🟢 Foundations
- **Complexity Analysis** — Big O, time and space
- **Arrays & Strings** — the building blocks
- **Linked Lists** — pointers and nodes
- **Stacks & Queues** — LIFO and FIFO

### 🟡 Core Data Structures
- **Hash Tables** — O(1) lookups
- **Trees** — hierarchical data
- **Binary Search Trees** — ordered trees
- **Heaps** — priority queues
- **Tries** — prefix trees

### 🔴 Advanced Algorithms
- **Sorting** — merge, quick, heap
- **Searching** — binary search
- **Graphs** — BFS, DFS, shortest path
- **Dynamic Programming** — optimal substructure
- **Greedy** — local optimal choices
- **Backtracking** — explore and backtrack
- **Bit Manipulation** — low-level optimization
