## 🤝 How to Contribute

### Step 1 — Build Your Project First

Make sure your project works on your computer.

Your project folder should look like this:

```
your-project-name/
├── README.md          ← What it does, insights, how to run
├── analysis.ipynb     ← Your notebook
├── data.csv           ← Dataset (small only, < 10 MB)
└── charts/            ← Optional visualizations
```

### Step 2 — Write a Clear README

Your project README should include:

- What the project analyzes
- Key insights found
- Tools used
- How to run it
- Screenshots (optional)
- Your name + GitHub link

**Template:**
# Project Name

## 🎯 What It Does
Short description

## 📊 Key Insights
- Insight 1
- Insight 2

## 🛠️ Tools Used
Pandas, Matplotlib, SQL...

## 🚀 How to Run
```bash
pip install -r requirements.txt
jupyter notebook analysis.ipynb
```

## 👨‍💻 Author
Your Name — [GitHub](https://github.com/your-username)

### Step 3 — Fork & Clone

```bash
# Fork this repo on GitHub, then:
git clone https://github.com/YOUR-USERNAME/python-ai-engineering-journey.git
cd python-ai-engineering-journey
```

### Step 4 — Add Your Project

Paste your project folder inside:

```
02 Data-Science-Job-Ready/10-Projects/your-project-name/
```

### Step 5 — Commit & Push

```bash
git add .
git commit -m "added my data science project - your-project-name"
git push origin main
```

### Step 6 — Open a Pull Request

1. Go to your fork on GitHub
2. Click **"Compare & pull request"**
3. Add title: `Added my DS project - your-project-name`
4. Add short description
5. Click **"Create pull request"**

### Step 7 — Wait for Approval

I'll review and merge it.

Once merged → **your project is live** 🎉
