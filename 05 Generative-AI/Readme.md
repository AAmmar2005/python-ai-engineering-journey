## 🎯 What is Generative AI?

Generative AI is the field of building AI systems that can **create** — text, images, code, audio, and more — using Large Language Models (LLMs) and modern deep learning.

**This folder takes you from zero → GenAI Engineer.**

---

## 📚 What You Will Learn

### 🟢 Foundations
- What is Generative AI?
- AI vs ML vs DL vs GenAI
- How LLMs work (high level)
- Tokens, context windows, temperature
- Open vs closed models (GPT, Claude, Llama, Gemini)

### 🟡 Core GenAI Skills
- **Prompt Engineering** — how to talk to LLMs properly
- **Embeddings** — turning text into vectors
- **Vector Databases** — Pinecone, Chroma, FAISS, pgvector
- **RAG (Retrieval-Augmented Generation)** — giving LLMs your own data
- **LangChain** — building LLM apps
- **LlamaIndex** — data frameworks for LLMs
- **Tool Calling / Function Calling** — let LLMs use tools
- **Fine-Tuning** — customizing models on your data
- **Structured Outputs** — JSON, Pydantic, function schemas

### 🔴 Advanced GenAI
- **AI Agents** — LLMs that act
- **Agentic AI** — autonomous workflows
- **Multi-Agent Systems** — agents working together
- **Agent Memory** — short + long term memory
- **Planning & Reasoning** — ReAct, CoT, ToT
- **Agent Orchestration** — LangGraph, CrewAI, AutoGen

### ⚙️ Production & Deployment
- **FastAPI** — serving LLM apps
- **Streamlit** — quick AI demos
- **Docker** — containerizing AI apps
- **Cloud Deployment** — AWS, GCP, Vercel
- **Cost Optimization** — cheaper inference
- **Monitoring & Evaluation** — LLM observability
