## 🤝 How to Contribute

### Step 1 — Build Your Project First

Make sure your agentic system works on your computer.

Your project folder should look like this:

```
your-project-name/
├── README.md          ← What it does, how to run
├── main.py            ← Your agentic system
├── requirements.txt   ← Libraries used
├── .env.example       ← Example env vars (NO real keys!)
└── screenshots/       ← Optional
```

### Step 2 — Write a Clear README

Your project README should include:

- What the system does
- What tools/frameworks it uses
- How to run it
- Screenshots (optional)
- Your name + GitHub link

**Template:**
# Project Name

## 🎯 What It Does
Short description (2-3 lines)

## 🛠️ Tech Used
LangGraph, CrewAI, AutoGen, etc.

## 🚀 How to Run
```bash
pip install -r requirements.txt
python main.py
```

## 📸 Demo
(musts)

## 👨‍💻 Author
Your Name — [GitHub](https://github.com/your-username)
```

### Step 3 — Fork & Clone the Repo

```bash
# Fork this repo on GitHub, then:
git clone https://github.com/YOUR-USERNAME/python-ai-engineering-journey.git
cd python-ai-engineering-journey
```

### Step 4 — Add Your Project

Paste your project folder inside:

```
07 Agentic-AI-Engineering/99-Projects/your-project-name/
```

### Step 5 — Commit & Push

```bash
git add .
git commit -m "added my agentic AI project - your-project-name"
git push origin main
```

### Step 6 — Open a Pull Request

1. Go to your fork on GitHub
2. Click **"Compare & pull request"**
3. Add title: `Added my agentic AI project - your-project-name`
4. Add short description
5. Click **"Create pull request"**

### Step 7 — Wait for Approval

I'll review your project and merge it.

Once merged → **your project is live in the main repo** 🎉
